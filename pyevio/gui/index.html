EVIO Stream Viewer

Drop an .evio file anywhere on this page. It is decoded in your browser and never uploaded. EVIO v6 with CODA streaming fADC250 data (0xFF60 time frames) gets full plots; any other EVIO v6 file shows the structure tree. File-based EVIO is untested; start with pyevio gui --mode=file to skip the streaming decode and go straight to the structure tree.
